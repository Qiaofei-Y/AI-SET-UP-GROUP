## 视觉风格

参考 [LangChain / LangSmith](https://info.langchain.com/ai-infrastructure) 的视觉语言重做:

- **暖米白背景 + 深青绿(teal)单一强调色**,不堆砌颜色
- **等宽字体做小标签(eyebrow / 状态 / 技术信息)**,营造技术编辑感
- **大量留白**,产品窗口带柔和光晕
- 顶部加了一个 LangChain 风格的**营销 Hero**,让营销面与产品面视觉统一

## 双语

- 页面中英文双语,**默认英文**。
- 右上角 `EN / 中` 切换,所有文案、输入框、标签实时切换。

## 怎么看

双击 `prototype.html` 用浏览器打开,顶部导航可跳转到各个界面。所有界面在一个画布上排列,模拟 Figma 的 Frame 视图。

## 7 个界面(对应 MVP 用户流程)

1. **欢迎 / 需求选择** —— 一个输入框开始一切 + 场景模板
2. **设备检测** —— 检测结果用人话展示,给出适配结论
3. **AI 推荐方案** —— 质量/速度/占用三个维度,技术细节收进"高级模式"
4. **安装进度** —— 每一步人话说明 + 失败可重试
5. **对话界面** —— 流式回答 + 来源引用
6. **知识库管理** —— 拖拽上传 + 索引状态
7. **AI Control Center** —— 模型/知识库/API/运行状态一屏管理

## 与 Figma 的关系

- 当前用 HTML 高保真原型交付(账号为 View 席位,暂无法在 Figma 创建设计文件)。
- 升级到 Editor 席位后,这套界面可以搬进 Figma 做交互原型与团队协作。
- 流程图与架构图已在 FigJam,见 [../docs/10-figma-diagrams.md](../docs/10-figma-diagrams.md)。

## 设计原则(硬约束)

- **对用户零技术名词**:界面不出现 VRAM、量化、Embedding、token,改用"质量/速度/占用空间"。
- **每步都有默认最优解**:用户全程可以只点"下一步"。
- **失败可恢复**:每一步可重试,错误用人话解释。
- **私有优先**:默认本地、默认数据不出设备。
