# 设计规范(Design System)

原型 [prototype.html](prototype.html) 使用的统一规范。

## 配色

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 Primary | `#4C6FFF` | 主按钮、强调、进度 |
| 主色深 | `#3B5BDB` | 悬停/按下 |
| 成功 Green | `#00B37E` | 检测通过、索引完成、运行中 |
| 强调 Purple | `#8B5CF6` | 微调 / Teach My AI 相关 |
| 警示 Orange | `#F97316` | 需注意、云端、失败诊断 |
| 正文 Text | `#1A1D29` | 主文字 |
| 次要 Muted | `#6B7280` | 辅助说明 |
| 边框 Border | `#E5E7EB` | 卡片/分割线 |
| 画布 Canvas | `#F0F1F3` | 应用背景 |

颜色与 FigJam 里的架构图保持一致,形成统一视觉语言。

## 字体

`Segoe UI` / `-apple-system` / `system-ui`(产品主打 Windows,首选 Segoe UI)。

- 标题:600–700 字重
- 正文:400–500 字重,14–16px
- 辅助:13px,Muted 色

## 圆角与间距

- 卡片圆角 12px,输入/按钮 8px,标签(pill)999px
- 基础间距节奏:4 / 8 / 12 / 16 / 24 / 32

## 核心组件

- **场景模板卡**:图标 + 标题 + 一句话,选中态描边主色
- **能力条(Meter)**:质量/速度/占用,用进度条表达,不出现技术数值
- **状态标签(Badge)**:已索引(绿)/ 处理中(蓝)/ 排队(灰)/ 失败(橙)
- **步骤条(Stepper)**:安装流程,完成打勾、当前高亮、未来置灰
- **来源引用(Citation)**:回答下方可点击的来源卡片

## 交互原则

1. 主操作永远是页面上最显眼的那个按钮,且是推荐项。
2. 技术细节一律收进可折叠的"高级模式",默认不展开。
3. 任何失败态都要有:人话原因 + 一个明确的下一步按钮。
