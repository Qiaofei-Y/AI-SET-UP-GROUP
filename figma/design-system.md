# 设计规范(Design System v2 · LangChain 风格)

原型 [prototype.html](prototype.html) 使用的统一规范。第二版参考 LangChain / LangSmith 的视觉语言重做:暖米白背景、近黑正文、等宽标签、单一强调色、大量留白。

## 视觉基调

- **暖色系,不用冷灰**:画布是奶油/米白,而非纯白或蓝灰,营造"高级、克制、技术编辑感"。
- **单一强调色**:深青绿(teal)贯穿品牌与主操作,不堆砌颜色。
- **等宽字体做小标签**:eyebrow / 状态 / 技术信息用 monospace,是这套视觉的签名特征。
- **大量留白**:充足的 padding 和行距,产品截图带柔和光晕。

## 配色

| 用途 | 色值 | 说明 |
|------|------|------|
| 画布 Paper | `#F4F1EA` | 暖米白背景 |
| 卡面 Surface | `#FBFAF6` | 卡片 / 窗口面 |
| 软填充 | `#F0EDE4` | 进度条底、chip |
| 正文 Ink | `#1B1A17` | 主文字(近黑) |
| 次要 Ink-2 | `#6B655C` | 暖灰辅助文字 |
| 边框 Line | `#E7E2D6` | 暖色边框 |
| **强调 Accent** | `#12695E` | 深青绿:品牌 + 主按钮 + 通过态 |
| 强调深 | `#0E514A` | 悬停 / 按下 |
| 强调淡 | `#E4EFEC` | teal 底色标签 |
| 信息 Info | `#3B6FD4` | "处理中 / 运行中"蓝 |
| 注意 Clay | `#B4622F` | 云端 / 失败 / 需注意(暖陶土色) |

三色纪律:**teal = 品牌与正向**,**blue = 进行中**,**clay = 需注意**。其余一律用暖中性色。

## 字体

- 正文/标题:`Inter` / `-apple-system` / `Segoe UI` / `PingFang SC`
- **标签/技术信息:等宽** `ui-monospace / SF Mono / JetBrains Mono / Menlo`
- Eyebrow:等宽 · 大写 · 加字距 · 前置小 teal 点

## 圆角与间距

- 窗口 16px,卡片 12px,按钮 8px,pill 999px
- 间距节奏:4 / 8 / 12 / 16 / 24 / 32 / 48 / 64

## 核心组件

- **Eyebrow 标签**:`● SECTION LABEL`,等宽大写,定位每一屏
- **能力条(Meter)**:teal / 中性,表达质量/速度/占用,不出现技术数值
- **状态标签(Badge)**:已索引/通过(teal)· 处理中/运行中(blue)· 排队(中性)· 失败(clay)
- **产品窗口(Frame)**:暖白面 + 柔和光晕 + 顶部窗口栏
- **来源引用(Citation)**:回答下方可点击来源卡

## 交互原则(不变)

1. 主操作是页面最显眼的按钮,且是推荐项。
2. 技术细节收进可折叠"高级模式",默认不展开。
3. 失败态 = 人话原因 + 一个明确下一步。
4. 对用户零技术名词(VRAM/量化/Embedding/token 一律不出现在用户界面)。
