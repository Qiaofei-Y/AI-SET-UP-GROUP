# 04 · MVP 范围

## 一个原则

**第一版不要试图支持整个 AI 世界。**

MVP 只为验证一件事:

> 普通人能不能真的在 20~30 分钟内,在几乎不懂 AI 技术的情况下,拥有自己的本地 AI?

如果这个成立,再扩展其他一切。

## MVP 做什么

| 范围 | 决定 |
|------|------|
| 操作系统 | 仅 **Windows** |
| 硬件 | 仅 **NVIDIA GPU** |
| 模型 | **5~10 个精选模型**(覆盖不同显存档位与用途) |
| 部署 | 仅**本地部署** |
| 知识 | 基础 **RAG**(PDF / Word / Excel / 文本) |
| 界面 | 简单 **Web UI**(对话 + 知识库管理) |
| 接口 | 本地 **API**(OpenAI 兼容格式) |

## MVP 明确不做什么

- ❌ macOS / Linux
- ❌ AMD / Intel GPU、纯 CPU 方案
- ❌ 云 GPU 部署
- ❌ Memory(长期记忆)
- ❌ Fine-tuning / LoRA(只做反馈数据收集的埋点预留)
- ❌ Agent / 工具调用
- ❌ 多用户、权限、企业功能
- ❌ 模型自由导入(只支持精选列表)

## MVP 用户流程

```
下载安装器 → 描述需求(或选模板)→ 自动检测设备
→ 展示推荐方案(人话)→ 点击安装 → 进度条
→ 打开 Web UI → 拖入文档 → 开始提问
```

## 成功标准

| 指标 | 目标 |
|------|------|
| 端到端时间 | 从下载到第一次成功问答 ≤ 30 分钟 |
| 安装成功率 | 在支持的硬件上 ≥ 90%(无人工干预) |
| 用户操作 | 全程不需要打开终端、不需要理解任何 AI 术语 |
| RAG 可用性 | 拖入文档后能正确回答基于文档的问题,并给出来源 |
| 验证方法 | 找 10~20 个真实的非技术用户实测,记录卡点 |

## MVP 之后的扩展顺序(初步)

1. macOS(Apple Silicon)
2. 云 GPU 选项(设备不够时的出路)
3. Memory
4. Teach My AI → LoRA 微调
5. Agent / 工具接入
6. Linux、企业功能
