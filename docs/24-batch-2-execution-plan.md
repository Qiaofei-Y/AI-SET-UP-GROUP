# 24 · 批次 2 执行计划:付费交付物本体(2026-09-01 起,1–2 月)

> 承接 [docs/23 上线冲刺](23-one-month-execution-plan.md)(批次 0/1,收钱链路代码侧已闭环,剩外部动作)。本文把 [docs/22 §6](22-commercial-readiness-audit.md) 的**批次 2 · 付费交付物**拆成可勾选、按依赖排序的执行清单。
>
> **为什么现在做**:批次 0/1 让陌生人能「注册→付款→退订」,但付费用户当前拿到的**交付物本体**仍是向导生成的 Ollama 引导安装包(真实可用,但非「双击即装、内嵌运行时 + 知识库」的成品体验)。批次 2 补的正是这块——把 P0-8(Tauri 真安装器)与 P0-9(本地 RAG)从「过渡方案」升级为「付费交付物」。
>
> **量级诚实**:批次 2 整体是 **L**,且首次触及需要真实 Windows/NVIDIA 硬件与代码签名证书的领域,代码侧无法像批次 0/1 那样完全自足测试。因此本计划显式区分**能在仓库内测试的代码工作** 与 **需要真机/证书/硬件的验收**,并把长周期外部动作(EV 代码签名证书)排在第一天并行启动。

## 验收(批次 2 完成)

一个有 NVIDIA GPU 的 Windows 用户:**下载签名安装器 → 双击安装(内嵌运行时)→ 按向导配置拉钉版模型 → 拖入自己的文档 → 索引后带来源作答**,全程无需命令行,安装成功率可度量。届时付费用户拿到的不再是引导脚本,而是「付费交付物本体」。macOS 与 Lambda 云路径转入后续批次。
