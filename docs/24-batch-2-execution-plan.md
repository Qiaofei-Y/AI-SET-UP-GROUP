## 验收(批次 2 完成)

一个有 NVIDIA GPU 的 Windows 用户:**下载签名安装器 → 双击安装(内嵌运行时)→ 按向导配置拉钉版模型 → 拖入自己的文档 → 索引后带来源作答**,全程无需命令行,安装成功率可度量。届时付费用户拿到的不再是引导脚本,而是「付费交付物本体」。macOS 与 Lambda 云路径转入后续批次。
