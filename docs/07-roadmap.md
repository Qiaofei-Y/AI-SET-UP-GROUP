# 07 · 路线图

> 时间为相对阶段,非承诺日期。每个阶段的推进以上一阶段的验证结果为前提。

## Phase 0 · 验证期(MVP)

**目标:证明"普通人 30 分钟拥有本地 AI"成立。**

- [ ] Windows + NVIDIA 一键安装器
- [ ] 设备检测(CPU / GPU / RAM / VRAM / 磁盘)
- [ ] 5~10 个精选模型 + 方案推荐(规则版即可,不必上来就很智能)
- [ ] 基础 RAG(PDF / Word / Excel / 文本,带来源引用)
- [ ] 简单 Web UI + OpenAI 兼容本地 API
- [ ] 部署数据埋点(为护城河打地基)
- [ ] 10~20 个真实非技术用户实测

**通过标准**:见 [04 MVP 范围](04-mvp.md) 的成功标准。不通过则迭代安装体验,不扩范围。

## Phase 1 · 扩平台

- [ ] macOS(Apple Silicon)支持
- [ ] 云 GPU 选项(本地设备不够时的出路)
- [ ] Model Registry 自动化(新模型自动收录、实测、上架)
- [ ] AI Control Center 完整版
- [ ] 更多精选模型持续收录、实测、上架(社区可提 PR 扩充 registry)

## Phase 2 · 让 AI 更懂用户

- [ ] Memory(长期记忆)
- [ ] Teach My AI 反馈循环全量上线
- [ ] 自动 LoRA / Fine-tuning 管线(含微调前后自动评测)
- [ ] 高级 RAG(更多格式、混合检索、增量索引)

## Phase 3 · 让 AI 干活

- [ ] Agent 能力与工具接入(邮件、日历、文件、常用 SaaS)
- [ ] 场景化 AI 模板:"采购 AI"、"公司知识 AI"、"研究 AI" → **Build My AI**
- [ ] Linux 支持

## Phase 4 · 更强的自托管与协作

- [ ] 多用户 / 权限 / 审计(团队自托管一套时用)
- [ ] 集中部署与管理(一台机器服务多人)
- [ ] 更完善的社区:模型贡献指南、示例库、插件/扩展点

## 贯穿所有阶段的主线

**AI Deployment Intelligence 数据积累**(见 [06 护城河](06-moat.md))——每个阶段的每个功能,都要回答"它给部署智能贡献了什么数据"。
