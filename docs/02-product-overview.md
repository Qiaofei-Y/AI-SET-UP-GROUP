# 02 · 产品概览

## 目标用户

**非技术用户**:不懂模型、GPU、RAG、LoRA、Docker、CUDA,但有真实的 AI 需求的人。

典型画像:

- 想要"完全私有的公司知识 AI"的中小企业主/管理者
- 想让 AI 读自己资料库的研究者、律师、会计、医生
- 关注数据隐私、不愿把资料上传给云端大模型的个人和团队

## 完整用户旅程

```
① 需求选择      用户用自然语言描述想要什么("我想要一个能读公司 PDF 的私有 AI")
② 设备检测      自动检测 CPU / GPU / RAM / VRAM / 操作系统 / 磁盘空间
③ AI 推荐方案   根据用途、预算、隐私、速度、用户数量推荐模型 + 部署方案
④ 本地/云端选择 设备够 → 本地;不够 → 云 GPU 或推荐硬件
⑤ 自动安装      模型、运行环境、RAG 组件、Web UI 全自动装好
⑥ 添加个人知识  拖入 PDF / Word / Excel / 邮件
⑦ RAG           自动解析、切片、Embedding、索引、检索
⑧ 使用          通过 Web UI 或 API 使用
⑨ 收集反馈      记录 "AI 回答 → 用户修改 → 正确答案"
⑩ 微调          数据足够后自动 LoRA / Fine-tuning
⑪ API/工具接入  连接用户的软件和工作流
```

## 核心体验原则

1. **一个输入框开始一切** —— 用户描述需求,不做技术选择题。
2. **技术名词零暴露** —— 界面上不出现 VRAM、量化、Embedding 这类词;必要时用"速度/质量/占用空间"表达。
3. **每一步都有默认最优解** —— 用户可以全程只点"下一步"。
4. **失败可恢复** —— 安装的每一步可重试、可回滚、有清晰的人话错误提示。
5. **私有优先** —— 默认本地、默认数据不出设备;云端是显式选择。

## 一个典型例子

用户输入:

> "我想搭建一个完全私有的公司知识 AI,可以读取 PDF、Excel 和内部资料。"

系统自动完成:

| 系统判断 | 输出 |
|----------|------|
| 用途分析 | 企业知识问答,隐私要求高 → 必须本地部署 |
| 设备检测 | RTX 4070 / 12GB VRAM / 32GB RAM / Windows 11 |
| 模型推荐 | 一个 12GB 显存下效果最好的开源模型 + 合适量化 |
| RAG 方案 | 文档解析器 + 英文优化 Embedding + 本地向量库 |
| 微调判断 | 暂不需要;先积累 Teach My AI 反馈数据 |
| 生成方案 | 引导式安装包(基于 Ollama,现已真实可用)+ 分步指南 + 预计安装时间 + 磁盘占用;带签名的一键安装程序随桌面应用推出 |
