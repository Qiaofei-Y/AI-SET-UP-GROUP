# 02 · 产品概览

## 目标用户

**主:开发者 / 自托管者** —— 想要一个可以完全拥有、数据不出边界的私有 AI 平台,而不愿从零拼装模型 / RAG / 账号 / 计费 / UI 的人:

- 要给团队或客户上线私有 AI、但不想把资料交给云端大模型的独立开发者、创业团队、内部平台组
- 有合规 / 数据驻留要求(法律、医疗、金融、政府供应商),必须自托管的团队
- 想在一个零依赖、可审计的底座上二次开发、嵌入自己产品的工程师

**次:参考产品的终端用户** —— 平台自带的参考产品面向**非技术用户**(不懂模型、GPU、RAG、Docker,但有真实 AI 需求的人);他们是开发者部署这套平台后所服务的对象:

- 想要「完全私有的公司知识 AI」的中小企业主 / 管理者
- 想让 AI 读自己资料库的研究者、律师、会计、医生

## 完整旅程 —— 两条视角

**开发者视角(自托管 + 扩展):**

```
① 获取        git clone,零依赖:无 pip install / npm install
② 自托管      本地一条命令 / Docker / 同源 HTTPS 反代 / 裸机 systemd(见 SELF-HOSTING.md)
③ 验收        curl /v1/health;跑 backend/frontend 两套测试
④ 集成 / 扩展  用 /v1/* API 驱动(见 examples/),或把参考产品当作起点改造
⑤ 运维        SQLite WAL + 版本化迁移、在线备份 + 恢复演练、body-free 结构化日志、CI
```

**终端用户视角(在开发者部署的参考产品里):**

```
① 需求选择      用自然语言描述想要什么("我想要一个能读公司 PDF 的私有 AI")
② 设备检测      自动检测 CPU / GPU / RAM / VRAM / 操作系统 / 磁盘空间
③ AI 推荐方案   根据用途、隐私、速度、用户数推荐模型 + 部署方案
④ 本地/云端选择 设备够 → 本地;不够 → 云 GPU 或推荐硬件
⑤ 自动安装      引导式安装包 + 分步指南
⑥ 添加个人知识  拖入 PDF / Word / Excel / 邮件
⑦ RAG           解析、切片、Embedding、索引、检索,答案带来源
⑧ 使用          通过 Web UI 或 API 使用
⑨ 收集反馈      记录 "AI 回答 → 用户修改 → 正确答案"(opt-in)
⑩ 微调          数据足够后自动 LoRA / Fine-tuning
⑪ API/工具接入  连接软件和工作流
```

## 核心体验原则

**对开发者:**

1. **自托管、零依赖、可审计** —— 一条命令跑起来;底座没有供应链要你操心。
2. **同源、单一出口** —— 浏览器只连 `127.0.0.1` 或自身源;生产用同源反代,前端 API 常量自动变 `''`,零配置。
3. **护栏随附** —— 账号 / 计费 / 迁移 / 备份 / 日志 / CI / 反代配置都在仓库里,不用自己攒。
4. **诚实 by design** —— 隐私红线写成测试断言,改坏即 CI 变红。

**对终端用户(参考产品):**

5. **一个输入框开始一切** —— 描述需求,不做技术选择题;技术名词零暴露(用「速度/质量/占用空间」表达)。
6. **每一步都有默认最优解,失败可恢复** —— 全程可只点「下一步」;每步可重试、可回滚、有人话错误提示。
7. **私有优先** —— 默认本地、默认数据不出设备;云端是显式选择。

## 一个典型例子(参考产品)

终端用户输入:

> "我想搭建一个完全私有的公司知识 AI,可以读取 PDF、Excel 和内部资料。"

系统自动完成:

| 系统判断 | 输出 |
|----------|------|
| 用途分析 | 企业知识问答,隐私要求高 → 必须本地部署 |
| 设备检测 | RTX 4070 / 12GB VRAM / 32GB RAM / Windows 11 |
| 模型推荐 | 一个 12GB 显存下效果最好的开源模型 + 合适量化 |
| RAG 方案 | 文档解析器 + 英文优化 Embedding + 本地向量库 |
| 微调判断 | 暂不需要;先积累 Teach My AI 反馈数据 |
| 生成方案 | 引导式安装包(基于 Ollama,现已真实可用)+ 分步指南 + 预计安装时间 + 磁盘占用;带签名的一键安装程序随桌面应用推出 |

而支撑这一切的顾问逻辑,就是开发者可直接调用的 `POST /v1/advise`(见 [examples/call-the-api.md](../examples/call-the-api.md))。
