# 11 · AI 架构与模型路由

> 回答一个核心问题:"Choose Your Need 该连什么 AI?能不能用云端模型省钱?"
> 结论:平台里有**两个不同的 AI**,别混为一谈。

## 两个 AI,别混淆

| | ① 方案顾问大脑(Advisor Brain) | ② 用户最终用的 AI(Deployed AI) |
|---|---|---|
| 干什么 | 读懂需求 → 推荐模型/硬件/RAG 方案 | 用户天天拿来问自己资料 |
| 什么时候跑 | 只在安装配置时跑一次 | 装好后长期、高频使用 |
| 跑在哪 | **默认规则表**,可选本机 LLM(`BMA_ADVISOR_LLM`,仅回环) | **默认用户本地**,可选云端(BYO-key) |
| 涉及隐私吗 | 否(用户只描述需求,未上传资料) | 是(要读用户的私密文档) |

"Choose Your Need 连什么 API"问的是 ①;"用云端省费用"落在 ②。

## ① 方案顾问大脑

**推荐:规则表为默认,可选本机 LLM 增强。** 顾问跑在你自己的机器上,和产品其余部分一样——**数据不出设备**,连安装配置阶段也不例外。

- **默认:规则表** `(场景, VRAM 档位) → 方案`(见 [09 工程任务清单](09-mvp-engineering-tasks.md) M2-2)。零外部调用、零 API 成本,确定可复现,足以验证产品假设。
- **可选:本机 LLM**。想让顾问听懂自由文本需求时,设 `BMA_ADVISOR_LLM=http://127.0.0.1:8080` 让 `/v1/advise` 调一个**本机**(仅回环)LLM 做意图分类/结构化提取,任何失败都回退规则表(端点规格见 [docs/20 §5](20-backend-architecture-and-api.md))。用哪个本地模型由你决定——任何 OpenAI 兼容的本机服务都行。

这一步用户只描述需求("我想要一个采购 AI"),**本就不涉及隐私**;把它也留在本机,是为了让"自持整套栈、数据不离开这台电脑"这句话没有例外。

## ② 用户最终用的 AI:本地默认 + 云端可选

"用云端省费用"的关键是**省谁的费用**:

| 方案 | 用户成本 | 隐私 | 适合 |
|------|----------|------|------|
| 本地部署 | 一次性买硬件,之后每次问答免费 | 最高,数据不出设备 | 有显卡、重隐私 |
| 云端调用 | 零硬件投入,按用量付费 | 数据出设备 | 无显卡 / 不敏感 / 想先试 |

**成本临界点**:本地 = 先付硬件、边际成本≈0;云端 = 零首付、按次付费。用得越多越久,本地越划算。

**隐私硬约束**:公司知识 AI 等场景**默认必须本地**("私有"就是卖点)。云端必须是**用户显式选择**,并明确提示"数据会离开这台电脑"。

> 参考实现:"本地 RAG → 本地模型 → 带来源引用回答"这条链路,已在演示站聊天页(`frontend/chat.html`)用本机 llm-lab 模型栈(llama.cpp + bge-m3,全程数据不出本机)跑通,见 [16 本地 AI 接入网页](16-local-ai-web-integration.md)。

## 为什么云端选项必须做

云端不是可有可无的便利,它是**设备不够的用户唯一的出路**:没有独显、或 VRAM < 6GB 的人,本地跑不动像样的模型。给他们一条「用自己的云账号、自付费」的路(BYO-key,见 [21 Lambda 云集成](21-lambda-cloud-integration.md)),项目不经手账单、不抽成。所以"云端调用"是**必须做的第二条路**,排在 MVP 之后(见 [07 路线图](07-roadmap.md) Phase 1)。

## 数据流与隐私边界(一张图说清)

```
安装配置阶段(默认全程本机):
  用户需求文本 ──→ ① 方案顾问(规则表 / 可选本机 LLM,仅回环)──→ 推荐方案
  ⚠️ 只处理"需求描述",绝不读用户文档;需求文本内存里用完即弃,不落盘

使用阶段(默认不出设备):
  用户文档 ──→ 本地 RAG ──→ ② 本地模型 ──→ 回答
                              └─(用户显式选云端时)─→ 云 GPU
```

**红线**:用户的**文档内容**在任何情况下都不随 ① 上云;埋点(见 [06 护城河](06-moat.md))也只收集硬件档位/方案/成败,**不含任何文档内容**。

## 最终愿景衔接

第四阶段"让 AI 连接软件替用户干活"会用到 **Claude 的工具调用 / Agent 能力**(Tool Use、MCP)。届时 ② 可以从"本地开源模型答问题"升级为"编排工具完成任务",本地模型负责隐私敏感部分,复杂 Agent 推理可路由到云端 Claude——同样遵守上面的隐私红线。
