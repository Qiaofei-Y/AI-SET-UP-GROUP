# 01 · 愿景与定位

## 一句话定位

**把复杂的开源 AI 世界,变成普通人也能一键拥有的个人 AI。**

## 我们要解决的问题

今天想拥有一个私有、本地、懂自己资料的 AI,用户必须理解:

- 模型选型(Qwen? Llama? 多大参数? 什么量化?)
- 硬件(GPU、VRAM、CUDA 版本)
- 运行环境(Docker、Python、驱动)
- RAG(解析、切片、Embedding、向量库、检索)
- 微调(LoRA、数据集格式、训练参数)

这些对普通用户是不可逾越的门槛。我们的平台把这一切全部隐藏在一个问题后面:

> "我想让 AI 帮我做什么?"

## 四阶段愿景

### 第一阶段:帮用户把 AI 装起来

需求 → 检测设备 → 推荐方案 → 一键安装。用户在 20~30 分钟内拥有一个能用的本地 AI。

### 第二阶段:帮用户把自己的资料交给 AI

拖入 PDF、Word、Excel、邮件,AI 自动理解并能基于这些资料回答问题(RAG)。

### 第三阶段:让 AI 越来越了解用户

通过 Memory 和 Teach My AI 持续收集"AI 回答 → 用户修改 → 正确答案",数据足够后自动 LoRA/微调,AI 越用越准。

### 第四阶段:让 AI 真正替用户完成工作

通过 API 和工具接入,AI 连接用户的软件和工作流,从"回答问题"进化到"完成任务"。

## 最终形态

用户甚至不需要选择"Qwen 还是 Llama"。用户只需要选择:

- "我要一个**采购 AI**。"
- "我要一个**公司知识 AI**。"
- "我要一个**研究 AI**。"

然后点击:

## **Build My AI**
