# 05 · 商业模式

## 订阅分层

### Free

目标:获客、积累部署数据。

- 基础模型推荐
- 本地一键部署
- 基础 Web UI

### Pro(个人付费)

目标:重度个人用户与自由职业者。

- 高级 RAG(更多格式、更好检索、引用溯源)
- 模型与组件自动更新
- Memory(长期记忆)
- Teach My AI 微调
- 本地 API
- 知识库备份与恢复

### Business(企业付费)

目标:中小企业。

- 企业知识库(共享、分组)
- 权限管理
- 多用户
- 审计日志
- 集中部署与管理

## 订阅之外的收入

| 收入线 | 说明 |
|--------|------|
| **云 GPU** | 设备不够的用户按量/包月使用云端算力,平台抽成 |
| **本地 AI 主机** | 预装平台的整机/硬件,面向"想要但没设备"的用户 |
| **企业部署** | 私有化部署项目制收费 |
| **技术服务** | 数据整理、知识库搭建、定制微调等服务 |

## 商业逻辑

- **Free 层不是成本,是数据来源**:每一次免费部署都在喂养 [AI Deployment Intelligence](06-moat.md)——什么硬件 + 什么任务 = 什么方案效果最好。
- **付费点设在"离不开"之后**:用户先在 Free 层拥有能用的 AI,当他开始依赖知识库、想要更准的回答(微调)、想接入工作流(API)时,才是自然的付费时刻。
- **企业是客单价放大器**:同一套技术,个人卖体验,企业卖权限/审计/集中管理。
