# web/ — 可用的多页网站

真正可运行的网站(不是设计稿)。双击 `index.html` 用浏览器打开即可。

## 结构

| 文件 | 作用 |
|------|------|
| `index.html` | **营销首页(宣传)**:Hero(带流式产品截图)、怎么运作、六大功能、本地/云端、价格、CTA |
| `build.html` | **功能子页(引导流程)**:需求 → 设备 → 推荐方案 → 本地/云端 → 生成文件 |
| `dashboard.html` | **Control Center 演示**:装好后的管理界面(模型/运行状态/知识库/API/Teach My AI) |
| `assets/styles.css` | 共享设计系统(LangChain 风格,与 `figma/` 一致) |
| `assets/i18n.js` | 中英文切换(默认英文,选择跨页面记忆) |
| `assets/build.js` | 向导逻辑 + **安装包/云端手册生成器** |

## 引导流程做了什么

1. **需求** —— 一句话或选模板(公司知识 / 写作 / 研究 / 通用)
2. **设备** —— 确认系统 / 显卡 / 显存 / 内存(真实产品会自动检测,网页里让用户确认)
3. **推荐方案** —— 规则引擎 `显存 → 模型档位`,用质量/速度/占用展示,技术细节收进"高级模式";并选择**本地 or 云端**
4. **生成文件** —— 浏览器**本地实时生成**并可下载:
   - 选**本地** → `build-my-ai-setup.ps1`(一键安装脚本)+ `install-plan.json`(方案清单)
   - 选**云端** → `cloud-deployment-guide.md`(为所选模型定制的部署手册,面向美国 GPU 服务器)

## 说明

- 生成的安装脚本/手册是**根据用户选择动态拼装**的,内含真实的模型仓库、下载源(Hugging Face)、llama.cpp 运行命令、RAG 配置等。
- 当前是**纯前端演示**:文件在浏览器里生成,不需要后端。接入真实检测/打包/后端时,替换 `build.js` 里的规则引擎和生成器即可。
- 设计与 `../figma/`(界面原型)、`../docs/11-ai-architecture-and-model-routing.md`(为什么顾问用 API、本地/云端)一致。
