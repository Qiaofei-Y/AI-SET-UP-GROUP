DEPLOYMENT

Run it where it makes sense

Private by default. Cloud when your computer isn't enough. Hybrid for the best of both.

💻 Local

Recommended for private data
  • Highest privacy — data never leaves
  • Free after setup · works offline
  • Needs an NVIDIA GPU

☁️ Cloud

When your computer isn't enough
  • No local GPU needed
  • Accessible from anywhere
  • Pay per use · data leaves device

🔗 Hybrid

Best of both (Pro) · auto-routing coming soon
  • Local model for private answers
  • Cloud for heavy or complex tasks
  • You choose what stays private
